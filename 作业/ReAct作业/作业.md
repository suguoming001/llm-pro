- 自定义实现 ReAct 代码实现效果如下
```python
# question = "长江和黄河的长度差是多少"
question = "笼子里有鸡和兔子工35只，脚共有94只，请问鸡和兔子各有多少只？"
agent = ReActAgentBuilder().with_model("deepseek-chat").with_max_steps(10).with_default_tools().with_verbose(True).build()
result = agent.solve(question)
if result.success:
    print(result.answer)
else:
    print(f"失败: {result.reason}")
```
